# data/ — Provenance README

Every file in this directory tree is documented here. Nothing in this repo is
Cynbit internal data.

## data/raw/ — public Cynbit website snapshots

Collected 2026-10-19 by `scripts/scrape.py` (httpx + BeautifulSoup, text-only
cleaning, provenance header in every file). Source: https://www.cynbit.in/
public marketing pages. No login, no access-control bypass, dynamic widgets not
captured. Authoritative file list with HTTP status and sizes:
`data/raw/_manifest.json`.

- `home.md`, `services.md`, `products.md`, `case-studies.md`, `story.md`,
  `team.md`, `careers.md`, `impact.md`, `bitelevate.md`, `bitelevate_paths.md`,
  `diaries.md`, `blog.md`, `contact.md`, `privacy.md`, `terms.md` — site pages.
- `blog_ai-agents-business-operations.md`, `blog_best-crm-automation-strategies.md`,
  `blog_small-business-ai-automation.md`, `blog_ai-digital-marketing-revolution.md`,
  `blog_ai-powered-business-guide.md` — the five most relevant posts.
- `_research_notes.md` — Phase-1 research summary with external citations.
- `_manifest.json` — machine-readable scrape manifest.

License note: Cynbit site content is © Cynbit Technologies; these snapshots are
text-only research extracts used here for analysis and grounding under fair-use
style research practice. The derived `app/assets/services_catalog.json` contains
short factual descriptors rewritten by this project.

## data/synthetic/ — SYNTHETIC DATA (not Cynbit internal data)

**SYNTHETIC DATA. Not Cynbit internal data.** All files in this folder are
machine-generated by `scripts/build_data.py` (fixed seed 42) or derived from
those generated files. No real Cynbit client, lead, or customer information is
present. Any resemblance to real inquiries is coincidental and unintentional.

- `leads_train.jsonl`, `leads_eval.jsonl` — labeled synthetic inbound inquiries
  (the evaluation split `leads_eval.jsonl` was never used for prompt tuning or
  few-shot selection; see decision.md D-011).
- `services_catalog.json` — curated, hand-written catalog of Cynbit's public
  service descriptions (grounded in data/raw/, rewritten), used for retrieval
  grounding. Not synthetic in origin, but contains only public marketing facts.
- `cached_outputs.json` — precomputed outputs for the built-in demo examples.
  Generated 2026-10-19 via live GLM calls through the build environment's GLM
  gateway (served model: glm-4-plus; the repo's live mode defaults to free-tier
  glm-4-flash — see decision.md D-003/D-014). Used by Offline Mode for the
  one-click examples; all other offline inputs use the deterministic engine.

## Regeneration

```
python scripts/scrape.py                  # re-collect raw pages
python scripts/build_data.py              # regenerate synthetic leads (seed 42)
python scripts/gen_cache.py               # regenerate cached_outputs (needs GLM key env, else offline fallback)
```
